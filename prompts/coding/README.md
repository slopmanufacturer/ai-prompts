# Coding

Prompts for reviewing, debugging, testing, and understanding code.

|---|---|---|
| [Senior Code Reviewer](./code-review.md) | Reviews your code like a senior engineer would — honest, not padded with praise | Beginner |
| [Explain This Diff](./explain-this-diff.md) | Plain-English walkthrough of a git diff, plus what could break | Beginner |
| [Regex Explainer + Builder](./regex-explainer-builder.md) | Builds or explains a regex, with a list of what it won't match | Beginner |
| [Rubber Duck Debugger](./rubber-duck-debugger.md) | Asks pointed questions one at a time until you find the bug yourself | Beginner |
| [Test Case Generator](./test-case-generator.md) | Lists the test cases worth writing, grouped by intent | Beginner |
